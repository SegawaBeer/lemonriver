title: Overview
description: Two CLIs — one to scaffold, one to run.
---

LemonRiver ships two CLIs:

- **`@lemonriver/cli`** — the scaffolder. One command (`init`) to bootstrap
  a new workspace.
- **`@lemonriver/core`** — the runtime CLI. `dev`, `build`, `preview`, and
  `sync:skills` for an existing workspace.

After `init`, `package.json` exposes the runtime CLI under standard scripts:

```json
{
  "scripts": {
    "dev": "LemonRiver dev",
    "build": "LemonRiver build",
    "preview": "LemonRiver preview",
    "sync:skills": "LemonRiver sync:skills"
  }
}
```

So in day-to-day use you'll just type `npm run dev`, `npm run build`, etc.
